# OpenForge Governance

OpenForge uses repository-based open governance.

Maintainers are responsible for merge quality, releases, security response, protocol compatibility and dependency/license hygiene. Contributors gain maintainer responsibilities through sustained, technically sound contributions and review participation rather than affiliation with a model or cloud vendor.

No model provider, editor, MCP server, ACP agent or hosted service is allowed to become a mandatory architectural dependency without an accepted ADR and a viable migration path.

Protected release branches should require CI, review, and signed/tagged release provenance. Security-sensitive or protocol-breaking changes require review by a maintainer familiar with the affected boundary.

This governance document describes project process and does not create a legal entity or replace the repository license.
