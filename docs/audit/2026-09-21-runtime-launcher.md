## Preserved boundaries

Revoking a lease records revocation; it cannot retract an environment-secret value already delivered to a client. Plugin capability declarations are inspected, not proof of runtime isolation. Stream synchronization applies to clones of one store instance; independent processes must not mutate the same upload directory concurrently. Live Sevi authentication requires the user's key. Installer package-download paths and GUI/IDE launches require OS/network/desktop prerequisites and are not equivalent to a clean-machine certification. These are concrete limits, not placeholder implementations.
