# Code of Conduct

OpenForge contributors are expected to keep technical collaboration professional, evidence-based and focused on the work.

Harassment, threats, discriminatory abuse, deliberate sabotage, credential exposure and knowingly deceptive security claims are not acceptable. Technical disagreement is welcome; personal attacks are not.

Maintainers may moderate issues, pull requests and community spaces to protect contributors and users. Security disclosures should follow `SECURITY.md`.
